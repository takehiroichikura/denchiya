株式会社電池屋 ・ 社内ツール（担当者限定）

サイボウズ ユーザー管理 MCP 利用ガイド

Claude のチャットから、cybozu.com のユーザー・組織・グループを確認したり、入退社にともなうアカウント作業を進められる社内コネクタです。利用できるのは許可された担当者だけです（現在：池田・市倉・青木）。

注意事項

  • これは正規のサイボウズコネクタではありません。生成AIで作成した電池屋用のコネクタです。正規のコネクタではないので、不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ知らせてください
  • 全社員のアカウント情報（氏名・ログイン名・所属）を扱います。回答や画面の内容を社外へ共有しないでください
  • このコネクタは全社員のアカウントを直接変更できます。特にユーザーの削除・停止は、その人のスケジュールやメッセージへのアクセスに即影響します。変更する操作は最大限気を付けてください

はじめる（初回だけ・3分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコード（INV-あなたの名前-…）が返ってきます。全コネクタ共通・30日有効。すでに持っていればこの手順は不要です
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-サイボウズMCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
このコネクタを使えるのは 管理者（市倉・青木・池田） です。役割に含まれない人は、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。自分の役割が分からないとき・権限の相談は市倉さんへ。

できないこと

やりたいことできる？理由・代わりの方法
スケジュール・メッセージ・ファイルなど業務データを読む✕このコネクタはユーザー管理APIだけです。Garoon や kintone の中身は対象外
パスワードの確認・初期化✕API では扱えません。cybozu.com 共通管理の画面で
ライセンスの追加・契約変更✕契約はサイボウズの管理画面から
管理者以外が使う✕全社員のアカウントを変えられるため、管理者3名に限定しています

まだできないこと（サイボウズ側の制約）

機能使えない理由
ログイン履歴・監査ログの取得ユーザー管理APIに含まれていません。共通管理の画面で確認
削除したユーザーの復元API にありません。削除は取り消せないので、退社対応は「停止」を使う

変更する操作（実装済→管理者向け）

変更する操作は18本あり、全社員のアカウントに直接影響します。どれも同じ流れで動きます：1回目はプレビュー（対象者と変更内容）→ 内容を見て承認 → 確認コードを付けた2回目でだけ実行。実行した記録（誰が・いつ・何を）はすべて残ります。

操作内容
add_users
ユーザー追加		起きること　新しいアカウントが作られる（ライセンスを消費）
取り消し　停止または削除
安全装置　ログイン名の重複を事前確認。所属は別ツールで付ける
update_users / update_user_codes
ユーザー変更		起きること　表示名・停止状態・ログイン名が変わる（停止は本人が即ログイン不可）
取り消し　元の値に戻す（プレビューに現在値）
安全装置　変更前後を並べて表示
delete_users
ユーザー削除		起きること　アカウントとその人のデータへのアクセスが消える
取り消し　不可
安全装置　削除は原則使わず「停止」。実行前に市倉さんに相談
update_user_organizations / update_user_groups / update_user_services
所属・サービス変更		起きること　見えるスケジュール・スペース・使えるサービスが変わる
取り消し　元の所属に戻す
安全装置　一括置き換えなので、外れる所属をプレビューで確認
add_organizations / update_organizations / update_organization_codes / delete_organizations
組織の操作		起きること　組織構成が変わる。親組織を削除すると子組織も削除され、配下の所属関係も解除される
取り消し　作り直し・付け直し
安全装置　削除対象の組織と所属人数をプレビュー。削除前に get_organization_users で所属者を確認する
add_groups / update_groups / update_group_codes / update_group_users / delete_groups
グループの操作		起きること　グループ構成・メンバーが変わる
取り消し　作り直し・付け直し
安全装置　メンバー変更は一括置き換え。外れる人をプレビュー
upload_file / import_csv
CSV一括更新		起きること　CSV の全行が一度に反映される
取り消し　逆内容の CSV を再投入
安全装置　件数と先頭行をプレビュー。まず export_csv で現状を控える
⚠️ 送信の途中で通信エラーになった場合は「送信したが受理されたか分からない」と表示されます。このときは再実行せず、get_users か cybozu.com 共通管理の画面で状態を確認してください。
