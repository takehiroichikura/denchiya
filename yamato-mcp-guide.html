ヤマト運輸 MCP 利用ガイド

Claude のチャットから、ヤマト運輸の荷物追跡（配達状況・履歴・注文番号からの逆引き・1日分の一括チェック）と、送り状の発行（B2クラウド API）ができる社内コネクタです。追跡は無料ですが、送り状の発行は 1 件ごとに料金がかかります。

💴 送り状の発行は 1 件 20 円（税抜）の API 利用料がかかります。
宅急便の運賃とは別に、ヤマトから月ごとに請求されます。発行した伝票は取り消せません（使わなかった分も 20 円は発生します）。 通常の出荷は今までどおり GoQ／スマートキャットで行い、Claude からの発行は返品交換の再送・例外出荷など少量の場合だけに使ってください。 様子見の期間として 1 日 50 件までに制限しており、超えると発行が止まって Chatwork に通知が飛びます。

注意事項

  • 利用は Claude デスクトップアプリの「Code」タブで行ってください。ブラウザ版の通常チャットではなく、Code の画面で質問・操作します
  • これは正規のヤマト運輸コネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ
  • 発行（issue_label）は必ず確認画面が先に出ます。「confirm: true」で実行するまで伝票は発行されません。確認画面の内容（お届け先・品名・種類）を必ず読んでから進めてください
  • PDF のダウンロード URL は 10 分間だけ有効です。開いてすぐ保存・印刷してください。逃した場合は B2クラウドの画面「発行済み」から印刷できます
  • お届け先の氏名・住所は個人情報です。追跡結果を Chatwork などに貼るときは伝票番号と状態だけにしてください

はじめる（初回だけ・3分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコードが返ってきます
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-ヤマトMCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
  4. 作業は Claude デスクトップアプリの「Code」タブで行います。アプリを開き、上部の Code を選んで新しいセッションを始めてください。コネクタは設定で一度オンにすれば Code 側でも使えます
荷物追跡は全員が使えます。送り状の発行は当面、市倉さんだけです（有料のため）。運用が固まったら物流の担当者に広げます。役割に含まれない人は「このコネクタの利用権限がありません」と表示されます。

💡 読み方のコツ：配達状況はヤマトの「荷物お問い合わせ」と同じ内容です。「荷物受付」「輸送中」は移動中、「配達中」は当日配達に出ている、「持戻」は不在などで営業所に戻った状態です。「ヤマトに未登録」は、まだ集荷情報が上がっていないか、伝票番号違いか、90 日を過ぎた荷物です。

拠点（契約）の選び方

ヤマトとの契約は 山梨・東京本社・茨城支店 の 3 つあり、MCP では account で切り替えます。荷物を実際に集荷してもらう拠点の契約を選んでください。ご依頼主の印字はどの契約でも本社（株式会社電池屋・渋谷区笹塚）で共通です。

account契約使いどころ
yamanashi山梨山梨倉庫から出す荷物。迷ったらこれ
tokyo東京本社本社から出す荷物（サンプル・書類・例外対応）
ibaraki茨城支店柏センコー（常総市）から出す荷物
発行では account の指定が必須です（運賃の請求先が変わるため）。追跡では省略でき、配達状況はどの契約で聞いても同じ結果です。お届け先情報付きの追跡や条件検索だけは、その荷物を出した契約で聞く必要があります。

送り状発行の流れ

  1. お届け先・品名・注文番号を伝える。ご依頼主（電池屋）と請求先コードは契約ごとの既定値が入るので言わなくてよい。宅急便コンパクト・ネコポス・コレクトなどは種類を指定
  2. Claude が B2クラウドの入力チェックにかけて確認画面を出す。住所の不備や必須項目の不足はここで分かる。この時点では発行されておらず、料金もかからない
  3. 内容を確認して「発行して」と伝える。ここで 20 円が発生し、伝票番号が確定する。取り消しはできない
  4. PDF の URL を開いて印刷する（10 分以内）。応答には伝票番号も載るので、そのまま追跡に使える
⚠️ 同じ注文に二重に発行しないでください。注文番号（お客様管理番号）は必須にしてあり、確認画面に表示されます。迷ったら発行前に この注文で今日すでに発行した？ と聞いてください。

できないこと

やりたいことできる？理由・代わりの方法
発行した伝票の取り消し✕API にありません。発行した時点で 20 円が確定します。使わない伝票は B2クラウドの画面で削除・請求対象外の手続きを
PDF をあとから取り直す✕印刷データは発行した通信の中でしか取れない仕組みです（実測）。10 分の URL を逃したら B2クラウドの画面「発行済み」から印刷
運賃を調べる✕B2 も荷物検索も運賃を返しません。ヤマトビジネスメンバーズの請求明細（画面）で
佐川・日本郵便の追跡✕ヤマトだけです。注文番号から調べたとき、他社配送は「追跡できません」と返ります
90 日より前の荷物✕ヤマト側の保存期間が 90 日です
お届け先情報付きの追跡・条件検索を夜間に△ヤマトの規約で 7〜23 時のみ。伝票番号だけの追跡は 24 時間できます
複数件をまとめて 1 枚の PDF に発行△今は 1 件ずつです。まとめ発行・印刷順の指定は需要があれば追加できます

作れるが作っていないこと

API はあるので技術的には作れますが、費用や事故の幅、既存の流れ（GoQ・スマートキャット・RPA）との衝突を考えて意図的に作っていないものです。必要になったら市倉さんへ。

やりたいこと状態作っていない理由・作るならこうなる

作れるが作っていない		1 件 20 円の従量課金なので、月数千件の通常出荷を乗せると数万円〜十数万円になります。通常出荷は GoQ／スマートキャットのまま。Claude からは例外分だけ
一般社員への発行の開放△
作れるが作っていない		権限の仕組みはあります。有料かつ取り消せない操作なので、当面は市倉さんだけ。運用が固まったら物流担当へ
毎朝の自動チェック（前日出荷分の持戻・保管中を Chatwork に投稿）△

まだできないこと（ヤマト側の制約）

機能使えない理由
荷物追跡の速さヤマトの規約で「1 回 20 件まで・前の応答から 5 秒あける」と決まっています。1 日分 2,000 件で約 10 分かかるのはこのためです
追跡の履歴の件数作業履歴は最新 5 件まで。それより前の経路は返りません
本物の伝票印字の事前確認検証環境ではダミーの PDF しか返りません。本番で最初に発行するときは自社宛に 1 枚出して印字を確認します

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「発行されているかどうか」まで書いてあります。「送信したあとの失敗です」と出たときだけ、再実行せずに B2クラウドの画面で発行状況を確認してください（再実行すると二重発行になります）
  • 「1 日の発行上限に達しました」と出たら、その日は API からの発行はできません。急ぐ分は B2クラウドの画面で発行し、上限の見直しは市倉さんへ
  • 「ヤマトに未登録」が続く伝票は、集荷がまだの可能性があります。翌日にもう一度
  • 招待コードはコダックへ To 付きで「招待コードをください」（期限切れも同じ）。「こういうことも聞けるようにしてほしい」という要望 → 市倉さん（システム担当）へ
