エアロジ MCP 利用ガイド

Claude のチャットから、倉庫管理システム「エアロジ（AiR Logi）」の在庫数・出荷実績・入荷実績を調べられる社内コネクタです。照会専用で、エアロジの内容を変える機能はありません。

注意事項

  • これは正規のエアロジコネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ知らせてください
  • 数字はリアルタイムではありません。エアロジには外から直接つなぐ口が無いため、エアロジが社内サーバに書き出したCSVの写しを見ています。在庫は毎日 0時過ぎ時点、出荷実績は1時間おき（9〜21時）、入荷実績は日中は1時間おき（11〜17時と20時）に更新されます。回答には必ず「いつ時点か（as_of）」が付くので、そこを確認してください
  • いま入っているデータは山梨倉庫だけです。柏（センコー）は品番と商品名しかエアロジから出ていないため、在庫・実績は見られません

はじめる（初回だけ・3分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコード（INV-あなたの名前-…）が返ってきます。全コネクタ共通・30日有効。すでに持っていればこの手順は不要です
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-エアロジMCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
このコネクタは 全員（管理者・ウェブチーム・一般） が使えます。役割に含まれない人は、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。自分の役割が分からないとき・権限の相談は市倉さんへ。

できること（聞き方の例）

分野こんなふうに聞く
在庫を調べる NPL1001 の山梨在庫は？／この5品番の在庫と出荷待機数をまとめて／「誘導灯」で商品名検索して在庫があるものだけ
出荷を確認する 注文番号 244970-2026… はいつ出荷した？伝票番号は？／今日ここまでにヤマトで出した件数は？／伝票番号 3031… はどの注文？
入荷を確認する 発注 OR938479ZX はもう入った？／今日、山善から入荷したものを一覧で／品番 TF3890B20 の直近の入荷はいつ？
補充の当たりをつける 発注点を下回っている品番を出して／在庫3以下でサンテレホンから仕入れているもの
データの鮮度 この在庫はいつ時点の数字？／エアロジの取り込みは動いてる？
💡 読み方のコツ：「引当可能」＝在庫数 − 出荷待機数 です。入荷実績は到着確認の記録で、ロケーション「z」は仮置き（棚入れ前）です。在庫数が空欄の品番は、エアロジで「在庫管理しない」設定になっているもの（無限在庫）の可能性があります。実数が必要なときはエアロジの画面で確認してください。
⚠️ 当日の動きは載っていません。在庫は毎日 0時過ぎの全件、出荷実績は毎時（最大1時間強の遅れ）です。「今の在庫」を確認したいときはエアロジの画面を見てください。

ツール一覧（7本）

AIが裏で使っている道具の一覧です。すべて照会専用です。

道具何をするか
get_stock品番を指定して在庫数・出荷待機数・引当可能数を返す（一度に100品番まで。見つからない品番は「該当なし」で返る）
search_items商品名・品番の一部・バーコード・メーカー・仕入先で商品を探す。在庫ありだけに絞れる
list_low_stock発注点を下回っている品番の一覧（しきい値の指定も可）
search_shipments出荷実績。注文番号 → 送り状番号（お荷物伝票番号）・出荷日・配送業者
search_receipts入荷実績。発注番号・品番・仕入先・日付で検索
data_status各データがいつ時点か、取り込みが動いているか
whoami接続の確認

できないこと

やりたいことできる？理由・代わりの方法
今この瞬間の在庫を見る✕エアロジには外から直接つなぐAPIがありません。見ているのは毎日0時過ぎに書き出された写しです。リアルタイムはエアロジの画面で
いま出荷した注文の伝票番号△出荷実績は9〜21時の毎時に出ます。最大1時間強遅れます。急ぐときはエアロジの画面か送り状システムで
柏（センコー）の在庫・出荷・入荷✕柏のエアロジからは品番・商品名・バーコードしか出力されていません。出力設定を追加すれば対応できます（市倉さんへ）
在庫を直す・出荷指示を入れる・商品を登録する✕照会専用です。エアロジへの投入は従来どおり RPA と画面で行います
ロケーション別の在庫✕商品マスタの出力に無い列です。入荷実績のロケーション欄は見られます
2026年9月より前の出荷・入荷実績✕取り込みは 2026年9月3日から始めています。それ以前はエアロジの画面で
無限在庫（在庫管理しない）かどうかの判定△在庫数が空欄なら可能性が高いですが、出力に判定列が無いため断定できません。画面で確認してください

まだできないこと（エアロジ側の制約）

機能使えない理由
外部からの直接接続エアロジに顧客向けの Web API がありません。公式ヘルプ全記事を確認済みです。唯一の連携手段が CSV のファイル交換なので、この方式を採っています
更新間隔を細かくするエアロジの自動出力は「毎日◯時」の定時実行しかありません。取り込み側は15分ごとに見ていますが、元の出力が日次です
Shift-JIS 以外の出力エアロジは Shift-JIS の CSV しか出せません。取り込み時に変換しています
2026年9月3日に作った新しいコネクタです。数字が画面と食い違うと感じたら、まず この在庫はいつ時点？ と聞いて as_of を確認し、それでも変なら市倉さんへ。

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 「まだ取り込まれていません」「取込日時が古い」と出るときは、社内サーバの取り込みが止まっている可能性があります → 市倉さんへ
  • 招待コードはコダックへ To 付きで「招待コードをください」（期限切れも同じ）。「こういうことも聞けるようにしてほしい」という要望 → 市倉さん（システム担当）へ
