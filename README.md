# denchiya — 電池屋 社内向け資料

株式会社電池屋の社内向け資料（Claude 用コネクタの利用ガイド・手順書・業務資料）を置いているリポジトリです。
GitHub Pages で公開していますが、全ページに `noindex` を設定しており、検索エンジンには載りません。

**閲覧は入口ページから**（URL は社内で配布しています。ここには書きません）。
