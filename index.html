MCP 利用ガイド（Claude 用コネクタ）

MCP は招待コードがないと使えません。各コネクタを初めてつなぐとき、認可画面で招待コード（INV-あなたの名前-…）の入力を求められます。 招待コードは全コネクタ共通で、発行から30日有効です。もらい方は下の図のとおりです。
  1. Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開く
  2. 入力欄の TO ボタンでコダックを宛先に選ぶ（TO が無いと返ってきません）
  3. 「招待コードをください」と送る
  4. 数秒で、あなた専用の招待コードが返ってくる。それを Claude の認可画面に貼る
