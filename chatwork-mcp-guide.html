Chatwork MCP 利用ガイド

Claude のチャットから、自分の Chatwork を読んだり、自分の名前で投稿・タスク登録ができる社内コネクタです。あなた自身の Chatwork トークンで動くので、見えるものも投稿の名義もあなた本人と同じです。

【最初にやること】自分の Chatwork APIトークンを申請してください。
このコネクタはあなた自身の Chatwork トークンで動きます。トークンの発行には組織管理者の承認が必要です（電池屋の設定）。
手順：Chatwork 右上の自分の名前 → サービス連携 → APIトークン を開き、「APIトークンの利用を申請」を押す → 承認されたら同じ画面にトークンが表示されます。 承認は市倉さんが行うので、申請したら Chatwork かチャットで一声かけてください。
RPA用など2つ目のアカウントがある人は、そのアカウントでも同じ手順で申請します。

注意事項

  • これは正規の Chatwork コネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ知らせてください
  • 投稿はあなたの名前で行われ、取り消せません。投稿・タスク登録の前には必ず確認画面が出ます。内容を読んでから承認してください
  • あなたの APIトークンは、あなたの社員IDにだけ紐づけて保存されます。他の人には見えません。トークンを他人に教えないでください（あなたとして何でもできる鍵です）

はじめる（初回だけ・5分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコード（INV-あなたの名前-…）が返ってきます。全コネクタ共通・30日有効。すでに持っていればこの手順は不要です
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-ChatworkMCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
  4. Chatwork で自分の APIトークンを発行する：Chatwork 右上の自分の名前 → サービス連携 → APIトークン。組織管理者（市倉さん）の承認が要るので、申請したら一声かけてください
  5. 【ここが忘れやすい】コネクタをつないだだけでは Chatwork は読めません。Claude に Chatwork のトークンを登録して。呼び名は たなか（自分の呼び名）、トークンは ◯◯◯ と伝えてください。Chatwork 上のあなたの名前が返ってくれば完了です。接続時にトークンは聞かれないので、必ずこの一言を送ってください

RPA用などアカウントを2つ持っている人は、呼び名を変えて（例 たなか と rpa）2回登録できます。以後は「rpa のアカウントで…」のように呼び分けます。

このコネクタを使えるのは 全員（管理者・ウェブチーム・一般） です。役割に含まれない人は、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。自分の役割が分からないとき・権限の相談は市倉さんへ。

できないこと

やりたいことできる？理由・代わりの方法
他人の投稿の編集・削除✕自分の投稿だけ編集・削除できます（確認画面あり）。他人の投稿は Chatwork の仕様上できません
グループの削除・退席✕削除するとメッセージ・タスク・ファイルが全部消えて戻せないため作っていません。Chatwork の画面で本人が行ってください（作成・名前変更・メンバー変更・招待リンクは確認画面つきでできます）
ファイルのアップロード△Claude が作った表やテキスト（CSV など）は upload_file で送れます。チャットに貼り付けた CSV・テキストも、Claude が中身を読み取って作り直したものとして送れます（原本そのままではなく、大きなファイルは途中で切れます）。Excel・画像・PDF はそのまま送れません。Claude はファイルの中身を文字として受け取るだけで、元のファイルそのものを持っていないためです。手元のファイルは Chatwork の画面から送ってください
他の人のアカウントとして読む・投稿する✕設計上できません。自分で登録したトークンの範囲だけです
自分がメンバーでないルームを読む✕Chatwork 側で権限エラーになります（本人の権限と同じ）
100件より前のメッセージ✕API が最新100件までしか返しません
短時間に大量に読む△1人あたり5分に300回、投稿は1ルーム10秒に10回の制限。超えると一定時間エラー

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 招待コードはコダックへ To 付きで「招待コードをください」（期限切れも同じ）。「こういうことも聞けるようにしてほしい」という要望 → 市倉さん（システム担当）へ
