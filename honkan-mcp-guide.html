本館（EC-CUBE）受注 MCP 利用ガイド

Claude のチャットから、本館（自社サイト・EC-CUBE）の受注を検索・参照できる社内コネクタです。照会専用で、EC-CUBE の内容を変える機能はありません。NetSuite にまだ流れていない注文（入金前・売上転記前）を調べるための道具です。

注意事項

  • 利用は Claude デスクトップアプリの「Code」タブで行ってください。ブラウザ版の通常チャットではなく、Code の画面で質問・操作します
  • これは正規の EC-CUBE コネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ知らせてください
  • 数字はリアルタイムではありません。EC-CUBE に外から直接つなぐ口が無いため、EC-CUBE から GoQ へ受注を取り込む RPA が社内サーバに書き出した CSV の写しを見ています。RPA が動くたびに更新され、取り込みは15分ごとです。回答には必ず「いつ時点か」が付くので、そこを確認してください
  • お客様の氏名・住所・電話・メールが含まれます。必要な範囲だけ使い、画面のコピーを社外に出さないでください
  • 本館（4系）だけです。旧サイト（2系）の受注は列の形が違うため、まだ取り込んでいません

はじめる（初回だけ・3分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコード（INV-あなたの名前-…）が返ってきます。全コネクタ共通・30日有効。すでに持っていればこの手順は不要です
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-本館受注MCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
  4. 作業は Claude デスクトップアプリの「Code」タブで行います。アプリを開き、上部の Code を選んで新しいセッションを始めてください
このコネクタの利用権限は個別に設定します。必要な人は市倉さんへ連絡してください。権限が無いと、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。

「状態」の読み方

元の CSV には EC-CUBE で売上転記されるまでの注文しか載りません。このコネクタは消さずに貯めているので、各注文に状態が付きます。

状態意味
取込中（売上転記前）最新の CSV にまだ載っている注文。入金待ちか、出荷準備中です
CSVから消えた（売上転記済み）EC-CUBE で売上転記が済んだ注文。「最終確認」の日時まではまだ載っていました。この注文は NetSuite 側にもあります
入金済みかどうかは、この状態では分かりません。GoQ で入金確認が付いた注文が NetSuite に流れるので、入金の有無は NetSuite に同じ注文番号（44-xxxxx）の受注があるかで確認してください。

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 探している注文が出てこないときは、売上転記済みで貯め始める前に消えた可能性があります。NetSuite で 44- の番号を探してください
  • 「まだ取り込まれていません」「取込日時が古い」と出るときは、RPA か社内サーバの取り込みが止まっている可能性があります → 市倉さんへ
  • 招待コードはコダックへ To 付きで「招待コードをください」（期限切れも同じ）。要望 → 市倉さん（システム担当）へ
