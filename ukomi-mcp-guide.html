U-KOMI 商品 MCP 利用ガイド

Claude のチャットから、本館（denchiya.net）のレビューサービス U-KOMI に登録されている商品・商品グループを調べて直し、レビュー・Q&A を読める社内コネクタです。レビューへの返信・公開／非公開は、別コネクタの U-KOMI 公式 MCP で行います。

注意事項

  • 利用は Claude デスクトップアプリの「Code」タブで行ってください。ブラウザ版の通常チャットではなく、Code の画面で質問・操作します
  • これは U-KOMI 公式のコネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。おかしな動きに気づいたら市倉さんへ
  • レビューにはお客様の氏名・メールアドレス・注文番号が付いています。普段は伏せた状態で返ります。表示させた内容を社外へ共有しないでください
  • 商品の登録・更新とグループの操作は U-KOMI の本番データを書き換えます。Claude は必ず「まだ実行していません」の確認を挟むので、内容を読んでから「実行して」と答えてください
  • U-KOMI 側は短い時間に続けて呼ぶと「リクエスト数が上限」になります。少し待って聞き直してください

はじめる（初回だけ・3分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、コダックが自動で返します（ほかのコネクタで使ったコードが期限内ならそのまま使えます）
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-U-KOMI商品MCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後1年間はコードの入力は不要です
  4. 作業は Claude デスクトップアプリの「Code」タブで行います。最初の一言は「U-KOMI に接続できてる？」（whoami）でつながりを確かめてください
このコネクタを使えるのは 管理者・ウェブチーム です。役割に含まれない人は、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。必要なら市倉さんへ

できること（聞き方の例）

分野こんなふうに聞く
商品 品番 2KR20CHS は U-KOMI に登録されてる？／グループ「ホーザン」の商品を一覧で／9月以降に更新された商品を 20 件／レビューが付いている商品だけ
商品を直す この品番の商品名と URL を直して／この 3 品番を新しく登録して（名前・URL・画像・価格）→ Claude が「今の値 → 新しい値」を見せるので、確認してから「実行して」
グループ 「パナソニック部品」というグループはある？／グループ ◯◯ に品番 A・B を入れて／グループ ◯◯ から品番 C を外して／空になったグループ ◯◯ を消して
レビュー 星 1〜2 のレビューを最近 10 件／品番 ◯◯ のレビューと平均点／グループ ◯◯ のレビューの星の内訳／先週投稿されたレビューはどの注文のもの？／非公開になっているレビューも含めて
Q&A 未回答の質問は何件？／品番 ◯◯ への質問を見せて
💡 商品 ID は本館の品番（例 2KR20CHS・ハイフン無し）です。グループは 5 万件以上あり、数字だけの名前（分類コード）も多いので、名前の一部で探すよう頼むと早いです。
⚠️ 個人情報の表示。レビューの氏名・メールアドレス・顧客 ID・注文番号と、Q&A の質問者の氏名・メールアドレスは、普段は伏せて返ります。必要なときだけ「氏名も出して」と頼んでください（includePersonal）。表示した内容を社外の文章に貼らないこと。

ツール一覧（16本）

AIが裏で使っている道具の一覧です。⚠️ は U-KOMI を書き換える道具で、必ず確認を挟みます。

道具何をするか
whoami接続状態（U-KOMI の鍵・トークンが使えるか）
get_accountU-KOMI のアカウント情報
search_products商品の一覧（グループ・タグ・作成日・更新日・レビュー有無で絞る）
get_products品番で商品の詳細（50 件まで）。ブラックリスト登録の有無・JAN なども
list_groupsグループの一覧（名前の一部で絞る・数字だけの名前を除く）

⚠️ delete_groupグループを消す（商品が入っていると U-KOMI が拒否するので、先に外す）

書き換えるときの流れ

  1. Claude に頼むと、まず「まだ実行していません」と、送る内容（商品なら 今の値 → 新しい値、グループなら今の中身）が表示されます
  2. 内容を読んで、よければ「実行して」と答えます。15 分以内・1 回限りです。内容を変えると、もう一度 1 からになります
  3. 実行後、Claude は U-KOMI から読み直して照合し、「完了」か「作成済み・要確認（どこが違うか）」を返します。要確認が出たら、U-KOMI の管理画面で確かめてください
⚠️ 「送信したあとの失敗」と出たときは、U-KOMI に反映されたかどうか分かりません。同じ内容をもう一度送る前に、「品番 ◯◯ を見せて」（get_products）や「グループ ◯◯ の中身」で確かめてください。

できないこと

やりたいことできる？理由・代わりの方法
レビューに返信する・返信を直す✕U-KOMI の公開 API にありません。U-KOMI 公式 MCP（設定 → コネクタの別の項目）で行ってください
レビューを公開／非公開にする、ラベル・ピックアップを付ける✕同上（公式 MCP で）
レビューを投稿する・削除する✕作っていません（投稿は社員が行うものではないため）。削除は U-KOMI でもできません（非公開にします）
商品を削除する✕U-KOMI の API に商品の削除はありません。管理画面で行ってください
注文データを U-KOMI に送る・取り消す✕作っていません（本館から自動で連携されています）
本館（EC-CUBE）の商品そのものを直す✕このコネクタは U-KOMI 側の商品データだけです。本館の商品は本館受注・商品 MCP（照会）か EC-CUBE の管理画面で

作れるけど作っていないもの

U-KOMI の API にはあるが、このコネクタには入れていない機能です。必要なら市倉さんへ（理由が「範囲の外」のものは足せます）。

機能足せる？入れていない理由
ブラックリスト商品の一覧・追加・削除（レビュー依頼メールを送らない商品）○今回の依頼（商品・グループ）の外なので保留。要るなら書き込みとして足します
いいね数の取得（レビュー・Q&A）○レビューのいいね数は search_reviews で返るので後回し
写真・動画のアルバム／ギャラリー（Visual UGC）○契約しているか未確認。使っているなら照会として足せます
複数グループまとめてのレビュー概要・細かい条件付きの概要○1 グループずつなら get_review_summary でできるので保留
顧客別のレビュー概要△顧客 ID 単位の集計で個人情報寄り。用途がはっきりすれば検討
注文データの取得・作成・取り消し△本館から自動で連携されています。作成・取り消しを誤るとレビュー依頼メールがお客様に飛ぶ／止まるため入れていません
レビューの投稿・いいね／低評価を付ける✕お客様が行うもの。社員が代わりに行うと口コミの偽装になるため作りません
ストアバッジ・FAQ・商品ページ用のメタ情報－Web ページの表示用で、社内で使う場面が無いため
💡 レビューへの返信・公開／非公開・ラベル・ピックアップは「作っていない」のではなく、U-KOMI の公開 API に無いので作れません。U-KOMI 公式 MCP で行ってください。

困ったとき

  • 「リクエスト数が上限」と出た → U-KOMI 側の制限です。1 分ほど待って聞き直してください
  • 「API キーかシークレットが違う」と出た → U-KOMI の設定が変わった可能性があります。市倉さんへ
  • コネクタが急に使えなくなった（再接続を求められる）ときは、認可の期限切れです。コダックに To 付きで「期限」と送ると状況を返します。コードを取り直して接続し直してください
  • 「新しくできるようになった」と聞いたのに Claude が「できない」と言うときは、設定 → コネクタ → 「ツールリストを更新」を押してください
  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 要望・不具合 → 市倉さん（システム担当）へ。レビュー運用の相談 → 池田さん
