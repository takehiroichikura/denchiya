NetSuite MCP 利用ガイド

Claude のチャットから NetSuite（オラクル） の受注・請求・発注・入荷・在庫・品目・取引先を調べられる社内コネクタです。あなた自身の NetSuite アクセストークンで動くので、見える範囲は NetSuite であなたのロールに見えるものと同じです。純正の NetSuite コネクタと違い、7日ごとに切れることはありません。

【最初にやること】自分の NetSuite アクセストークンを発行してください。
NetSuite にログイン → ホーム（家のアイコン）→ 左の「設定」ポートレット → 「アクセストークンの管理」（直接開くなら こちら）→ 「新しいマイアクセストークン」。アプリケーション名は 電池屋 Claude MCP、ロールは普段使っているもの（電池屋社員 など）、トークン名は自動で入る名前のままでOK。
保存するとトークンIDとトークン・シークレットが表示されます。この画面を閉じると二度と見られません。閉じる前に下の「はじめる」の手順5へ進んでください。
「設定」ポートレットに「アクセストークンの管理」が無い人は、ロールに権限がありません。市倉さんに連絡してください（市倉さんが代わりに発行して渡すこともできます）。ポートレット自体が無いときは、ホームの「パーソナライズ」から「設定」を追加できます。

注意事項

  • これは正規の NetSuite コネクタではありません。生成AIで作成した電池屋用のコネクタです。不具合が入っている可能性があります。数字がおかしいと感じたら NetSuite の画面で確かめてください
  • 見える範囲・できることは、あなたの NetSuite のロールと同じです。Claude 経由で見えないものは、画面でも見えないものです
  • 変更できるのはメモ・外部ID・カスタム項目だけで、金額・数量・ステータス・明細は変更できません。変更は必ず確認画面が先に出て、NetSuite の変更履歴にはあなたの名前で残ります
  • トークンはあなたの社員IDにだけ紐づけて暗号化して保存されます。他の人には見えません。トークンを他人に教えないでください（あなたとして NetSuite を操作できる鍵です）
  • NetSuite の在庫は基幹の帳簿在庫です。倉庫の実在庫（エアロジ）と違うことがあります。倉庫の数字はエアロジ MCP で

はじめる（初回だけ・5分）

  1. 招待コードを手に入れる。Chatwork で コダック（RPA用アカウント）とのダイレクトチャットを開き、To を付けて「招待コードをください」と送ると、数秒で自分専用のコード（INV-あなたの名前-…）が返ってきます。全コネクタ共通・30日有効。すでに持っていればこの手順は不要です
  2. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-NetSuiteMCP をオンにする
  3. 初めて使うときに認可画面が開くので、招待コードを貼り付けて「接続を許可する」を押す。以後、コードの入力は二度と不要です
  4. NetSuite で自分のアクセストークンを発行する：ホーム → 「設定」ポートレット → 「アクセストークンの管理」（直接開く）→ 「新しいマイアクセストークン」。アプリケーション名「電池屋 Claude MCP」、ロールは普段のもの、トークン名は自動で入る名前のまま → 保存。保存後の画面の下部「トークンID/シークレット」に2つの値が出ます
  5. 【ここが忘れやすい】コネクタをつないだだけでは NetSuite は読めません。Claude に NetSuite のトークンを登録して。呼び名は たなか（自分の呼び名）、トークンIDは ◯◯◯、シークレットは ◯◯◯、メールは 自分のアドレス と伝えてください。NetSuite 上のあなたの名前が返ってくれば完了です。接続時にトークンは聞かれないので、必ずこの一言を送ってください
  6. 登録が済んだら、NetSuite のトークン画面を閉じ、トークンの控えは残さない

メールアドレスは表示用の名前を引くためだけに使います（省略可）。トークンをなくしたら、同じ「アクセストークンの管理」で古いものを取り消し、「新しいマイアクセストークン」で作り直してもう一度登録してください。

このコネクタを使えるのは、いまのところ 管理者 です（ウェブチームへの開放は準備中）。役割に含まれない人は、正しい招待コードを入れても「このコネクタの利用権限がありません」と表示されます。自分の役割が分からないとき・権限の相談は市倉さんへ。

できないこと

やりたいことできる？理由・代わりの方法
受注・請求書などの新規作成✕作っていません。必須項目の推測や二重登録の事故を避けるため。作成は NetSuite の画面か RPA で
金額・数量・ステータスの変更✕影響が大きいため対象外。変更できるのはメモ・外部ID・カスタム項目だけ
保存検索の実行✕REST 経由では保存検索を直接実行できません。同じ条件を SuiteQL で書いて実行します（「◯◯という保存検索と同じものを SuiteQL で」と言えば Claude が組みます）
レポート（財務レポート等）の実行✕REST に無い機能。純正 NetSuite コネクタか画面で
自分のロールで見えないデータ✕NetSuite 側で権限エラーになります（本人の権限と同じ）
倉庫の実在庫・棚番✕NetSuite は帳簿在庫です。倉庫の実数・ロケーションはエアロジ MCP で
大量の全件取得△1回 1,000 行まで。続きがあるときは Claude が「まだ続きがある」と伝え、必要なら次ページを取ります

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 「トークンが無効」と出たら、NetSuite でトークンが取り消されたか、コピー漏れです。アクセストークンの管理 で古いものを取り消し、「新しいマイアクセストークン」で作り直して register_token で登録し直してください
  • 「権限がありません」は、あなたのロールにその操作の権限が無い状態です。市倉さんに相談してください
  • 招待コードはコダックへ To 付きで「招待コードをください」（期限切れも同じ）。「こういうことも聞けるようにしてほしい」という要望 → 市倉さん（システム担当）へ
