UiPath MCP 利用ガイド

Claude のチャットから、社内RPA（UiPath Orchestrator）の実行状況・失敗の原因・ロボットの稼働状態を調べたり、ジョブの実行・再実行などの操作ができる社内コネクタです。「RPAが動いてない気がする」のような聞き方で大丈夫です。

注意事項

  • これは正規のUiPathコネクタではありません。生成AIで作成した電池屋用のコネクタです。正規のコネクタではないので、不具合が入っている可能性があります。おかしな動きに気づいたら、そのまま使い続けずに市倉さんへ知らせてください
  • このコネクタは動いている業務のRPAを直接操作できます（ジョブの実行・停止・再実行、トリガーの有効/無効など）。停止や再実行は出荷・発注などの業務処理に直結するため、変更する操作は最大限気を付けてください
  • RPAのログには注文番号などの業務データが含まれることがあります。回答や画面の内容を社外へ共有しないでください

はじめる（初回だけ・3分）

  1. Claude の「設定 → コネクタ」を開き、一覧の 電池屋用-UiPath MCP をオンにする
  2. 初めて使うときに認可画面が開くので、招待コード（INV-あなたの名前-…）を入力する。楽天MCPと同じコードです（コネクタごとに入力は必要ですが、コードは1人1つ）
  3. 「接続を許可する」を押して完了。以後、コードの入力は二度と不要です

招待コードの有効期限は発行から30日（約1か月）です。期限切れ・紛失のときは市倉さんに再発行を依頼してください（1分で再発行できます）。

できること（聞き方の例）

分野こんなふうに聞く
稼働状況 今RPAは何が動いてる？／今日失敗したジョブはある？／ロボットはちゃんとつながってる？
失敗の調査 発注書作成のジョブ、なんで落ちたの？（実行ログから例外の内容まで読めます）／最近のエラーログを見せて
実行・操作 ◯◯のプロセスを実行して／さっき失敗したジョブを再実行して／実行中の◯◯を止めて／◯◯のトリガーを一時的に無効にして
設定の確認 スケジュール（トリガー）の一覧を見せて／アセット◯◯の値は？／このプロセスのバージョンは最新？

できないこと

  • RPAプロセスの中身の修正・新規作成 — UiPath Studioの領域です
  • 監査ログ（誰が設定を変えたか） — 準備中です（権限の追加待ち）
  • スケジュール（トリガー）の新規作成・削除 — 影響が大きいため対象外。有効/無効の切り替えのみできます

変更する操作（実行・停止など）の約束ごと

AIがプレビューを出す→自分の目で確認→OKなら実行を指示

ジョブの実行・停止・再実行などの「変更する操作」は、いきなり実行されることはありません。AIが必ず対象と内容のプレビュー（どのプロセスを・どのロボットで・どんな条件で）を見せてくるので、確認してから実行を伝えてください。実行した記録（誰が・いつ・何を）はすべて残ります。

⚠ RPAの停止・再実行は、出荷・発注・受注取込などの業務処理そのものに影響します。「このジョブを止めていいか」「再実行して二重処理にならないか」の判断に迷ったら、実行せずに担当者か市倉さんに確認してください。
変更系のツールは、会社の方針で最初は「ブロック」になっている場合があります。業務で必要なときは、コネクタ設定の「ツールの権限」で該当ツールを有効にしてください（判断に迷ったら市倉さんへ）。

困ったとき

  • エラーが出たら、まずエラー文を読んでください。「次に何をすればいいか」まで書いてあります
  • 招待コードの再発行、権限の相談、「こういうことも聞けるようにしてほしい」という要望 → 市倉さん（システム担当）へ。要望は「どの業務で・何を知りたい／したいか」を添えてもらえると早く作れます
