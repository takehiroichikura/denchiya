電池屋MCPのしくみ

Claude に「楽天の受注を見て」「エアロジの在庫は？」と聞くと答えが返る。その裏で何が動いているかを、専門用語をほどきながら説明します。読む時間は10分ほどです。

ひとことで言うと、Claude に電池屋専用の「道具」を持たせている仕組みです。

Claude（AI）自身は、楽天やエアロジの中身を知りません。そこで、電池屋が自分で作った小さなプログラムを「道具」として Claude に渡しています。Claude は質問に応じてその道具を使い、結果を読んで、日本語で答えます。道具の実体は Cloudflare というクラウド上で動いています。

登場する言葉

  • Claude クロード
    AIアシスタント。Anthropic 社が提供
    私たちが会話している相手です。文章を読んで理解し、必要なら「道具」を使って調べ、答えを組み立てます。電池屋は Anthropic のサービス（Claude.ai）を利用しています。
  • MCP エムシーピー
    Model Context Protocol。AIに道具を渡すための共通ルール
    「AIから外のシステムを呼ぶときの決まり事」です。この決まりに沿って作れば、どんなシステムでも Claude の道具になります。電池屋の10本のコネクタはすべて MCP の決まりで作ってあります。
  • コネクタ Claude の画面での呼び名
    Claude の「設定 → コネクタ」に並ぶもの
    MCP サーバーを Claude 側から見た名前です。「電池屋用-楽天MCP」をオンにする、というのは、楽天の道具を Claude に持たせる操作です。
  • Cloudflare クラウドフレア
    道具を動かしているクラウド。Workers という仕組みを使う
    電池屋の道具（プログラム）はここで動いています。サーバー機を買わず、世界中のデータセンターで小さなプログラムを動かせるサービスで、10本合わせて月5ドル程度です。
  • API エーピーアイ
    システム同士が話すための窓口
    楽天RMS・Yahoo!・Amazon・Chatwork などは、画面を開かずにデータをやりとりする窓口（API）を用意しています。電池屋の道具はこの窓口を叩いてデータを取ってきます。
  • 招待コード OAuth 認可
    道具を使える人を決める鍵
    初めてコネクタをつなぐときに1回だけ入れるコードです。「この Claude を使っているのは電池屋の誰か」を道具側が確認する仕組みで、コードを持たない人には道具が動きません。

質問してから答えが返るまで

たとえば「NPL1001 の在庫は？」と聞いたとき。Claude が品番を読み取り、エアロジの道具を選び、道具がデータを返し、Claude が文章にします。
  1. 社員が Claude に日本語で聞く。「楽天の未出荷は何件？」「発注 OR938479ZX は入荷した？」。話し言葉でかまいません。
  2. Claude が使う道具を選ぶ。コネクタごとに「何ができる道具か」の説明が付いていて、Claude はそれを読んで選びます。人が「楽天MCPを使って」と指示する必要はありません。
  3. Cloudflare 上の道具が動く。その社員が招待コードで認可済みか、役割にそのコネクタが含まれるかを確かめてから、相手のAPIを呼びます。ID・パスワード・APIキーは道具の中に暗号化して保管してあり、Claude には渡りません。
  4. 相手のシステムがデータを返す。楽天や Chatwork は API で直接。エアロジだけは API が無いため、エアロジがFTPに毎時出力するCSVの写しを Cloudflare に保管して、そこから答えます。
  5. Claude が結果を読んで答える。数字の意味づけや要約は Claude の仕事です。いつ時点のデータかも一緒に返るので、Claude はそれを添えて答えます。

安全のために入れている仕組み

  • 招待コードと役割コードを持つ電池屋の社員だけが使えます。さらに役割（管理者・ウェブチーム・一般）で、使えるコネクタが決まります。
  • 鍵は道具の中に楽天やAmazonのAPIキーは Cloudflare 上の道具が暗号化して保管します。Claude にも社員にも渡りません。
  • 変更は2段階で確認投稿・更新など「変える」操作は、まず内容を表示し、確認の合図があったときだけ実行します。確認の合図は15分で無効になり、1回しか使えません。
  • ほとんどが参照専用10本のうち大半は見るだけの道具です。エアロジ・Amazon Pay・価格.com は変更する道具を持ちません。
  • 記録が残る誰がどの道具をいつ使ったかは記録されます（入力した品番や本文の中身は記録しません）。
  • 個人情報は伏せる購入者の氏名・住所を返す道具は作っていません。Amazon Pay は既定で購入者情報を隠します。

よくある質問

  • 電池屋のデータは外に出るの？
    Claude が答えを作るために、取得したデータは Anthropic の Claude に送られます（会話に貼り付けたのと同じ扱い）。電池屋の契約では会話内容は AI の学習に使われません。道具そのものは電池屋の Cloudflare アカウント上で動き、他社と共有していません。
  • 「Claude API」と何が違う？
    Claude API は、プログラムから Claude を直接呼ぶための窓口です。今の仕組みは逆向きで、Claude.ai の会話の中から電池屋の道具を呼んでいます。将来「毎朝自動で楽天の問い合わせをまとめて Chatwork に出す」のような無人処理を作るときは、Claude API を使って道具を呼ぶ側になります。
  • 数字はリアルタイム？
    API でつながっている楽天・Yahoo!・Amazon・Chatwork などは、聞いた時点の値です。エアロジだけは「エアロジがCSVを書き出した時点」で、在庫は毎日0時、出荷・入荷は1時間おきです。答えに「いつ時点か」が付きます。
  • Claude が勝手に注文を変えたりしない？
    変える操作は、内容を表示して確認の合図を待ちます。合図なしに実行されることはありません。また、注文キャンセルなど影響の大きい操作は道具として作っていません。
  • 誰が作って、誰が直すの？
    Eコマース部システム課（市倉）が作り、保守しています。コードの置き場所と設計メモは社内 Git に残してあり、外部のAIによるコードレビューも通しています。不具合や要望は市倉まで。
  • 壊れたらどうなる？
    道具が止まっても、楽天やエアロジの本体には影響しません。道具は「見る・API越しに操作する」だけで、相手のシステムの中身を直接いじる立場にないからです。Claude は「エラーで取れませんでした」と答えます。
  • 費用は？
    Cloudflare は10本合計で月5ドル（約750円）です。Claude の利用料は会社の契約に含まれます。相手先のAPIは各サービスの契約に含まれていて追加費用はありません。
