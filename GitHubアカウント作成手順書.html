GitHubアカウント作成手順書

GitHub(ギットハブ)は、研修の後半(9月)で「Skill(AIへの手順書)」を保存・共有する練習に使うサービスです。 今回は研修の課題用なので、ふだんお使いの個人のGoogleアカウントで作成してください。 新しくメールアドレスを用意する必要はありません。

1/5

手順1. GitHubのページを開く

ブラウザ(ChromeやEdge)で、次のアドレスを開きます。下のようなログイン画面が表示されます(この画面から新規登録もできます)。

https://github.com/login
2/5

手順2. 「Continue with Google」から自分のアカウントを選ぶ

画面の下のほうにある「Continue with Google(Googleで続行)」のボタンをクリックします。メールアドレスやパスワードの入力欄は使いません。

下のようなGoogleの画面に切り替わったら、ふだん使っている自分のGoogleアカウントを選択します。

  • 複数のアカウントが表示される場合は、どれを選んだか覚えておいてください(次回ログインで同じものを使います)。

続いて、下のような確認画面(「GitHub にログイン」)が表示されます。内容を確認して「次へ」を押してください。これでGoogleアカウントとの連携は完了です。

3/5

手順3. ユーザー名を決める

下のような「Sign up for GitHub」という登録フォームが表示されます。上から順に、次のように入力してください。

  • Email: 選んだGoogleアカウントのアドレスが自動で入っています。そのままでOKです。
  • Username(ユーザー名): 半角英数字で入力します。研修で誰のアカウントか分かるよう、自分の姓(ローマ字)を含めてください。例: 山田さん → yamada-yd、yamada-taro など。入力欄の右に緑のチェックが付けば使える名前です(すでに使われている名前は登録できません。数字などを足してください)。
  • Your Country/Region: 「Japan」を選びます。
  • GitHub Copilot: 最初からチェックが入っている場合がありますが、外して構いません(今回の研修では使いません)。
  • Email preferences: チェック不要です。

入力できたら、緑色の「Create account」ボタンをクリックします。これでアカウント作成は完了です。

4/5

手順4. ログインできることを確認する

登録が終わったら、いちどブラウザを閉じ、あらためて https://github.com を開いてください。

  • 下のような画面(Dashboard)が開き、画面右上に丸いアイコン(下の画像の赤丸の位置)が表示されていればログイン済みです。
  • ログイン画面が出た場合は「Sign in with Google」から手順2と同じGoogleアカウントを選んでください。
5/5

手順5. 課題用のリポジトリを作る

ここがゴール

リポジトリ(repository)は、研修で作るSkillを保存する「フォルダ」のようなものです。ログインした状態で、次の手順で1つ作成してください。

手順4の画面の左側にある、緑色の「Create repository」ボタンをクリックします。(見当たらない場合は、画面右上の「＋」マーク →「New repository」でも同じ画面が開きます)

「Create a new repository」という画面が開くので、次のように設定します。

  • Repository name: denchiya と入力します(全員共通の名前です。半角小文字)。下に緑色で「denchiya is available.」と出ればOKです。(下の画像では「test」と入っていますが、皆さんは denchiya と入力してください)
  • Choose visibility(公開範囲): 最初は「Public」になっています。赤枠のボタンをクリックし、必ず「Private(プライベート)」に変更してください。
  • Add README: 赤枠のスイッチをクリックして「On」にします。
  • Add .gitignore / Add license: そのまま(No)で構いません。
  • 最後に右下の緑色「Create repository」ボタンをクリックします。

リポジトリのページが表示されれば完了です。中身はまだ空(READMEのみ)で構いません。研修で使います。

補足A. 「2段階認証(2FA)」の設定画面が出た場合

人によっては、登録の途中や初回ログイン時に「2段階認証を設定してください」という画面が出ることがあります。出なければ設定不要です。出た場合だけ、画面の案内に従って設定してください。

  • 選択肢が出たら「SMS(携帯電話のショートメッセージ)」を選ぶのが簡単です。携帯番号を入力し、届いた数字のコードを画面に入力します。
  • 「リカバリーコード」が表示されたら、印刷するかメモして保管してください。
  • うまくいかない場合は、無理に進めず研修用のChatworkグループへ連絡してください。

補足B. すでにGitHubアカウントを持っている場合

新しく作り直す必要はありません。手順4と同じ方法でログインできることを確認し、手順5のリポジトリ作成だけ行ってください。

困ったときは

途中でエラーが出た、どのアカウントで作ったか分からなくなった、など困ったことがあれば、そのままにせず研修用のChatworkグループへ投稿してください(個別のメールではなくグループ宛にお願いします)。
